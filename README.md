# List

A simple program for working with tabular data. Allows you to open, view, edit and save tables.

## Features

- Open and save tables in text format
- Add, delete and rename attributes
- Add, delete and edit records
- Set table name

## Usage

1. Compile and run the program.
2. Use the "File" menu to open or save tables.
3. Manage the table using commands in the "Control" menu.
4. Edit values in the table directly in the table.

## Building

The project uses wxWidgets for creating a graphical interface. To build, you need to install wxWidgets and configure the path to the libraries in the project file.
